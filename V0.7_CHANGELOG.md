# MT Developer DNA V0.7 değişiklik raporu

- Yeni `dna-deploy` workspace crate'i eklendi.
- Codex, Claude Code ve Gemini CLI provider keşfi ile project/global scope ayrıldı.
- Deterministik SHA-256 manifest, paket/adaptör/şema sürümleri ve install registry eklendi.
- Dry-run plan, idempotent install, sync, update, backup-and-replace çatışma politikası,
  transaction lock, atomik yazma ve kullanıcı değişikliğini koruyan rollback eklendi.
- Doctor çıktısında PASS, WARN, FAIL, NOT_RUN ve UNSUPPORTED durumları korundu.
- Mevcut V0.1–V0.6 komutları ve `.mt-dna` proje hafızası sözleşmesi korundu.
- Masaüstü uygulaması, daemon, watcher ve sürekli polling eklenmedi.
