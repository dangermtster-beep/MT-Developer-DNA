# MT Developer DNA V0.5 geliştirme ve doğrulama raporu

## Mimari sonuç

V0.1–V0.4 API'leri korunarak `dna-quality` süreç ve ölçüm sınırı eklendi. Sistem
talep üzerine çalışır; masaüstü uygulaması, daemon, watcher veya sürekli polling yoktur.
Format/lint kontrolleri verify/check modundadır; otomatik düzeltme yetkisi vermez.

## Uygulanan bileşenler

- Tool discovery ve yüklü araç sürümü kanıtı
- Program/argüman ayrımlı CheckRunner, timeout, iptal ve çıktı sınırı
- Yedi dil için genişletilebilir test/quality/build/security adapter'ları
- Deterministik quality gate ve strict release-check
- Windows elapsed, CPU time ve peak working set ölçümü
- Üç veya politika tarafından seçilen sınırlı tekrar ve medyan süre
- Ortam/iş yükü uyumlu baseline karşılaştırması
- Bounded yerel kritik sır taraması
- Hassas yol/token redaksiyonlu JSON ve Markdown raporları
- `.mt-dna/reports/*` ve `.mt-dna/baselines/performance.json` entegrasyonu

## Epistemik sınırlar

Eksik araç `NOT_RUN`, desteklenmeyen metrik `UNAVAILABLE` olur. Zorunlu eksik kontrol
release'i `BLOCKED` yapar. Python `compileall` gerçek test/paketleme başarısı sayılmaz.
Temiz yerel veya ekosistem taraması güvenlik garantisi değildir. Baseline yalnızca aynı
ortam, komut ve iş yükünde karşılaştırılır.

## Açıkça raporlanan başarısız/çalıştırılamayan kontroller

- İlk debug self-test, çalışan `target/debug/dna-cli.exe` dosyasını Cargo yeniden
  üretmek istediği için Windows kilidiyle FAIL oldu. Release EXE üzerinden tekrarlandı
  ve PASS oldu.
- Release EXE'nin doğrudan kendi `target/release` konumundan yaptığı ilk self
  `release-check`, aynı Windows dosya kilidi nedeniyle build FAIL verdi. Artefakt ayrı
  doğrulama dizininden çalıştırıldığında build PASS oldu; nihai gate yalnız eksik
  `cargo-audit` nedeniyle BLOCKED kaldı.
- Claude Code `plugin validate` komutu skill dizinini plugin manifesti sanarak
  `.claude-plugin/plugin.json` istedi ve çalıştırılamadı. Skill yapısı bağımsız skill
  validatorüyle PASS oldu; etkileşimli `/mt-developer-dna` çağrısı canlı oturumda
  ayrıca doğrulanmalıdır.
- Gemini CLI kurulu olmadığı için canlı skill/slash komut testi çalıştırılamadı.
- Cargo'nun incremental cache hard-link işlemi bu dosya sisteminde desteklenmedi;
  Cargo kopyalamaya düştü. Bu çevresel uyarı derleme, Clippy veya test sonucunu
  başarısız yapmadı.

Temiz tarama güvenlik garantisi değildir. Çalışmayan provider veya harici scanner
yanlışlıkla PASS olarak gösterilmemiştir.
