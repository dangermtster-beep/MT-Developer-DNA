# V0.2 değişiklik raporu

## Korunan sözleşmeler

- Workspace crate adları: `dna-core`, `dna-render`, `dna-cli`.
- `Profile::load`, `Profile::from_json_str`, `Profile::validate`.
- `Provider::{Codex, Claude, Gemini}`, `ProviderPackage`, `RenderedFile`.
- `render_package`, `validate`, `preview` ve `export` davranışları.
- V0.1 JSON fixture'ı değişmeden yüklenir ve seçilen dil provider çıktılarında korunur.

## Eklenen yetenekler

- Canonical universal skill ve progressive-disclosure referansları.
- Genişletilebilir ve bağımsız doğrulanabilir dil profili şeması.
- Provider adapter sınırı ve provider'a özgü çağırma dosyaları.
- Gerçek kurulum öncesi diff, açık onay, yedek, atomik değiştirme, idempotency ve
  açık onaylı rollback.
- Yerel provider CLI sürüm denetimi.

## Güvenlik kararları

- Onaysız kurulum dosya yazmaz.
- Render edilen yollar normal göreli bileşenlerle sınırlıdır.
- Proje kökü ve hedeflerde symlink/reparse geçişleri reddedilir.
- Eski dosya içeriği değişiklikten önce yedeklenir.
- Rollback yedeği silmez; tekrar inceleme ve kurtarma için korur.
- API anahtarı veya gizli bilgi provider paketine alınmaz.

## Doğrulama sınırları

- Codex ve Claude CLI sürümleri yerelde algılanmıştır.
- Claude yardım çıktısı `/skill-name` çağrısını doğrulamıştır.
- Gemini CLI yerelde kurulu değildir; adapter resmi dosya yapısına göre test edilmiştir,
  canlı model oturumu doğrulanmamıştır.
- Örnek/golden çıktılar test fixture'ıdır; kurulu üretim entegrasyonu olarak sunulmaz.
