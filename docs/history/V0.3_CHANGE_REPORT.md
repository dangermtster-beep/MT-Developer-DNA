# MT Developer DNA V0.3 değişiklik raporu

Tarih: 16 Ekim 2026

## Durum tespiti

V0.2 başlangıcında `dna-core`, `dna-render` ve `dna-cli` bağımlılık yönü temizdi;
profil/dil doğrulaması, üç provider renderer'ı, güvenli install/rollback ve 19 test
çalışıyordu. Mevcut public `Profile`, `Provider`, `ProviderPackage` ve
`render_package` sözleşmeleri değiştirilmedi.

## Uygulanan V0.3 kapsamı

- Yeni `dna-memory` crate'i `.mt-dna` şemasını ve dosya yaşam döngüsünü yönetir.
- Başlatma ikinci çağrıda veri silmez; tüm yazma akışları önce plan/diff üretir.
- Update seçili dili değiştiren parametre kabul etmez; resume ve handoff aynı dili
  raporlar.
- Manifest nesli, dosya hash'leri ve kısa ömürlü kilit sessiz eşzamanlı veri kaybını
  önler. Değişen dosyalar onarım/güncelleme öncesi yedeklenir; manifest en son
  atomik yazılır.
- `.env` ve build/dependency klasörleri taranmaz. Kullanıcı metinleri allowlist
  alanlarına alınır ve şüpheli sırlar yazma öncesi redakte edilir.
- Audit; eksik dosya, JSON/şema, dil, hash, yerel link, şüpheli sır ve kaynak
  güncelliği sorunlarını ayırır. `0.2.0` hafıza şeması repair planında `0.3.0`a
  yükseltilebilir; bozuk JSON anlaşılır hata üretir.
- Provider çıktıları ortak `.mt-dna` kaynağı ve altı hafıza niyeti için gerçek
  Codex/Claude/Gemini çağırma biçimlerini taşır.

## Kaynak kullanımı

Uygulama yalnızca CLI komutu sırasında sınırlı dosya I/O'su yapar. Watcher,
polling, arka plan servisi, GPU işi veya masaüstü arayüzü eklenmedi. RAM/CPU için
ölçülmemiş kesin performans iddiası yoktur.

## Doğrulama

- `cargo fmt --all -- --check`: geçti.
- `cargo clippy --workspace --all-targets -- -D warnings`: geçti. Cargo'nun çalışma
  alanı dosya sistemi için bildirdiği incremental-cache hard-link uyarısı kod veya
  Clippy uyarısı değildir.
- `cargo test --workspace`: 29 test geçti, hata yok.
- `cargo build --workspace --release`: optimize derleme geçti.
- Skill Creator `quick_validate.py`: canonical skill geçerli.
- Gerçek CLI kabulü: onaysız init yazmadı; onaylı init/update/handoff, yedek,
  `memory check` ve `resume` geçti.
- Codex CLI `0.156.1` ve Claude Code `2.1.216` yerelde algılandı. Gemini CLI kurulu
  olmadığı için canlı Gemini oturumu doğrulanmadı; renderer/golden testi geçti.
- Windows canlı symlink oluşturma denemesi yönetici ayrıcalığı olmadığı için
  yapılamadı. Reparse/symlink ret kodu mevcut; path traversal entegrasyon testi
  geçti. Bu ayrım canlı kabul yerine PASS uydurulmaması için korunmuştur.

Provider konum ve çağırma biçimleri 16 Ekim 2026'da OpenAI, Anthropic ve Gemini
CLI resmi belgeleriyle yeniden karşılaştırıldı. Canlı model çağrısı yapılmadı.

## V0.4 adayları

- Kullanıcı onaylı dil değişikliği için açık ADR/migration akışı.
- Daha güçlü, sürümlü kriptografik manifest hash algoritmasına geçiş.
- Yarım kalmış çok-dosyalı işlem için journal tabanlı crash recovery.
- Kurulu Gemini CLI ortamında canlı skill/command kabul testi.
